# Discipline Profile: Education Research

## ID
`education`

## Research Methodology

- **Primary methods**: Action research, quasi-experimental design, design-based research, survey research, case study, ethnography, phenomenology, narrative inquiry, mixed methods, program evaluation, learning analytics
- **Evidence types**: Pre/post test scores, survey responses (Likert), interview transcripts, classroom observation data, student artifacts, learning logs, assessment rubrics, effect sizes (Cohen's d), qualitative themes
- **Validation standards**: Pre-registration for experiments, effect sizes with confidence intervals, trustworthiness criteria for qualitative (credibility, transferability, dependability, confirmability), triangulation, member checking, ethical review
- **Claim structure**: "Intervention X improved learning outcome Y for population Z (d=A, p=B)" or "Analysis reveals that students experience phenomenon P through process Q"

## Paper Structure

### Quantitative Education Paper
```
1. Introduction (1-2 pages)
2. Literature Review (2-3 pages)
3. Research Questions / Hypotheses (0.5 page)
4. Methods (2-3 pages) — participants, context, measures, procedures, analysis
5. Results (3-4 pages)
6. Discussion (2-3 pages)
7. Implications for Practice (1 page)
8. Conclusion (0.5-1 page)
```

### Qualitative Education Paper
```
1. Introduction (1-2 pages)
2. Literature Review / Conceptual Framework (2-3 pages)
3. Methodology (2-3 pages) — paradigm, design, participants, data collection, analysis, trustworthiness
4. Findings (5-7 pages)
5. Discussion (2-3 pages)
6. Implications for Practice and Research (1-2 pages)
```

### Citation Style
- APA 7th edition (standard for education journals)

## Review Dimensions

| Dimension | Weight | Description |
|-----------|--------|-------------|
| Research Question | 15% | Is the question educationally significant and well-grounded? |
| Theoretical Framework | 15% | Is there an appropriate conceptual/theoretical lens? |
| Methodological Rigor | 25% | Is the design sound for the question asked? |
| Evidence Quality | 15% | Are findings well-supported by the data? |
| Contribution | 10% | Does this advance educational knowledge or theory? |
| Practical Implications | 15% | Can findings inform teaching, policy, or curriculum? |
| Ethical Practice | 5% | Are participants protected and represented fairly? |

## Discipline-Specific Rules

- **Context matters enormously**: Always describe the educational context (grade level, subject, institution type, cultural setting)
- **Practical implications required**: Unlike pure social science, education papers must discuss implications for practice
- **Student voice**: Increasingly valued — include student perspectives when possible
- **Ecological validity**: Lab-based findings must discuss transfer to real classroom settings
- **Equity lens**: Consider how findings relate to diverse student populations
- **Intervention fidelity**: Report how faithfully the intervention was implemented
- **Multiple measures**: Use more than one measure of learning outcomes when possible
