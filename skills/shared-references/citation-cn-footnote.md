## 脚注 vs 尾注选择

| 期刊/场景 | 引注方式 | 说明 |
|-----------|---------|------|
| 法学研究 | 脚注（页下注） | 全文连续编号，圈码①②③…… |
| 中国法学 | 脚注（页下注） | 全文连续编号，方括号[1][2]…… |
| 中外法学 | 脚注（页下注） | 全文连续编号 |
| 体育科学 | 尾注（文末参考文献） | 顺序编码制，正文中[1][2]标注 |
| 法学家 | 脚注（页下注） | 全文连续编号 |
| 法商研究 | 脚注（页下注） | 全文连续编号 |
| 博士论文 | 脚注（页下注） | 各校要求不同，多用全文连续编号 |
| 默认 | 脚注（页下注） | 法学类论文默认使用脚注 |

**规则**: 以目标期刊/学校的投稿须知为最终标准。当不确定时，法学类默认脚注，体育学类默认尾注（参考文献表）。

## 脚注体例总则

### 编号规则
- **全文连续编号**: ①②③…… 或 [1][2][3]……（取决于期刊要求）
- 法学研究用圈码①，中国法学用方括号[1]
- 每条脚注独立成段，首行无缩进或缩进两字符（随期刊）

### 标点规则
- 脚注末尾用句号"。"结束
- 书名用书名号《》，外文书名用斜体
- 页码前用"第"字，如"第123页"；或用"页"字后置，如"123页"（随期刊）
- 中文文献中的标点一律使用中文全角标点

### 作者姓名规则
- 中文作者: 直接写全名，不加标点。如"王利明"
- 多作者: 用顿号"、"分隔，三人以上可"第一作者等"
- 外文作者在中文脚注中: 保持原文姓名，不翻译
- 译者: 在作者后标注"[国籍]作者名著，译者名译"

## 著作类引用

### 基本格式
```
作者: 《书名》，出版社出版年版，第X页。
```

### 示例

**单作者专著:**
```
王利明: 《物权法论》，中国政法大学出版社2003年版，第156页。
```

**多作者专著:**
```
梁慧星、陈华彬: 《物权法》，法律出版社2007年第5版，第89页。
```

**译著:**
```
[德]卡尔·拉伦茨: 《法学方法论》，陈爱娥译，商务印书馆2003年版，第45页。
```

**古籍:**
```
张廷玉等: 《明史》卷七十五《职官志四》。
```

**编著/主编:**
```
王利明主编: 《民法学》，中国人民大学出版社2015年第7版，第234页。
```

## 期刊论文引用

### 基本格式
```
作者: 《文章标题》，载《期刊名》年第X期，第X页。
```

### 示例

**中文期刊:**
```
苏力: 《法条主义、民意与难办案件》，载《中外法学》2009年第1期，第93页。
```

**注意**: 部分期刊要求省略"载"字:
```
苏力: 《法条主义、民意与难办案件》，《中外法学》2009年第1期，第93页。
```

**有卷号的期刊:**
```
张新宝: 《个人信息保护的制度框架》，载《法学研究》2022年第44卷第3期，第1页。
```

### 集刊（连续出版但无正式刊号）
```

## 法律法规引用

### 总则
- 法律法规首次引用时写全称，后续可简称
- 注明具体条、款、项、目
- 已修订的法律标注修订时间

### 格式与示例

**法律:**
```
《中华人民共和国体育法》（2022年修订）第50条第1款。
```

**行政法规:**
```
《全民健身条例》（2016年修订）第28条。
```

**部门规章:**
```
国家体育总局《体育赛事活动管理办法》（2023年）第15条。
```

**地方性法规:**
```
《北京市全民健身条例》（2017年）第12条。
```

**已废止法律（历史引用）:**
```
《中华人民共和国体育法》（1995年）第32条（已被2022年修订版替代）。
```

### 条款层级规范
```
第X条          — 条
第X条第X款      — 款（自然段序号）
第X条第X款第X项  — 项（（一）（二）……）
第X条第X款第X项第X目 — 目（1. 2. ……）
```

## 案例引用

### 中国案例

**裁判文书:**
```
XX诉XX案，XX人民法院（年）X民/刑X号民事/刑事判决书。
```

### 示例

**民事判决:**
```
新浪互联体育公司诉天盈九州公司侵害著作权纠纷案，北京知识产权法院（2015）京知民终字第1818号民事判决书。
```

**指导性案例:**
```
最高人民法院指导案例第X号: 案件名称（案号）。
```

### 示例
```
最高人民法院指导案例第81号: 张某诉某体育公司劳动合同纠纷案（（2014）杭滨民初字第1234号）。
```

**公报案例:**
```
XX案，载《最高人民法院公报》20XX年第X期。
```

## CAS仲裁裁决引用

### 基本格式
```
CAS Award, Case No. CAS XXXX/X/XXXX, [Parties], [Date], para. XX.
```

### 示例

**普通仲裁:**
```
CAS Award, Case No. CAS 2018/A/5546, Club A v. Player B, 15 March 2019, para. 124.
```

**奥运仲裁:**
```
CAS Ad Hoc Division (OG Tokyo), Case No. CAS OG 20/03, Athlete X v. IOC, 28 July 2021, para. 56.
```

**中文行文中可加简要说明:**
```
在CAS 2018/A/5546号仲裁案中，仲裁庭认为……。参见CAS Award, Case No. CAS 2018/A/5546, Club A v. Player B, 15 March 2019, paras. 120-130。
```

## 外文文献引用

### 总则
- 中文脚注中引用外文文献，保持外文原样，不翻译标题
- 书名用斜体，文章标题用引号
- 遵循来源语言的学术引用惯例

### 英文著作
```
Author Name, Book Title in Italics (Publisher Year), p. XX.
```

### 示例
```
Michael Beloff, Tim Kerr & Marie Demetriou, Sports Law (2nd edn, Hart Publishing 2012), p. 156.
```

### 英文期刊
```
Author Name, "Article Title", Journal Name in Italics, Vol. X, No. X (Year), p. XX.
```

### 示例
```
Antoine Duval, "The Olympic Charter: A Transnational Constitution Without a State?", Journal of Law and Society, Vol. 45, No. 2 (2018), p. 245.
```

### 德文、日文等其他外文
保持原文格式，必要时在括号内注明语种或中文译名:
```
Karl Larenz, Methodenlehre der Rechtswissenschaft (6. Aufl., Springer 1991), S. 312.
```

## 网络文献引用

### 基本格式
```
作者: 《文章标题》，载XX网站，发布日期，访问日期，URL。

### 示例
```
张三: 《体育赛事数据保护的困境与出路》，载中国法学网，2023年5月10日发布，2024年3月1日最后访问，http://www.iolaw.org.cn/xxxxx。

### 政府网站
```
国家体育总局: 《关于体育赛事活动监管意见》，载国家体育总局官网，2023年6月发布，2024年1月访问，https://www.sport.gov.cn/xxxxx。

## 重复引用简写规则

### 紧邻引用（同一注释来源紧接上一条）
```
同上注，第78页。
```
或
```
同前注⑤，第78页。
```

### 非紧邻引用（引用此前已出现的文献）

**中文文献:**
```
前引注③，王利明文，第156页。
```
或（部分期刊格式）:
```
同前注③，第156页。
```

**外文文献:**
```
See supra note 5, Beloff et al., p. 200.
```
或直接用拉丁简写:
```
Beloff et al., supra note 5, at 200.
```

### 注意事项
- 首次引用必须完整
- "同上注"仅用于紧邻前一条的相同文献
- "前引注X"指向具体注释编号，必须标明页码变化
- 部分期刊不接受"同上注"，要求每次完整引用——以投稿须知为准

## 期刊特殊要求速查

### 《法学研究》
- 脚注，圈码①②③编号，全文连续
- 作者与书/文名之间用冒号": "
- 期刊用"载《期刊名》"
- 页码用"第X页"
- 外文文献保持原样

### 《中国法学》
- 脚注，方括号[1][2][3]编号
- 格式与法学研究接近但编号不同
- 有独立的注释体例文件，以官网最新版为准

### 《体育科学》
- **尾注（参考文献表）**，非脚注
- 顺序编码制，正文中[1][2]标注
- 基本遵循GB/T 7714-2015
- 格式: `[序号] 作者.题名[文献类型标志].刊名,年,卷(期):页码.`
- 示例: `[1] 韩勇.体育赛事转播权的法律属性[J].体育科学,2020,40(3):45-53.`

### 《体育与科学》
- 尾注（参考文献表），顺序编码制
- 遵循GB/T 7714-2015

### 《中外法学》
- 脚注，全文连续编号
- 格式与法学研究相近

## LaTeX实现方案

### 方案一: 手动脚注（推荐用于法学类）

法学论文通常不使用 BibTeX 管理引用，而是直接在正文中使用 `\footnote{}`:

```latex
\documentclass[12pt,a4paper]{ctexart}
\usepackage{geometry}
\geometry{left=3cm,right=3cm,top=2.5cm,bottom=2.5cm}

% 脚注设置
\usepackage[perpage,symbol*]{footmisc}  % 可选：每页重新编号
% 或者使用全文连续编号（默认）

% 圈码脚注编号（法学研究风格）
\usepackage{pifont}
\renewcommand{\thefootnote}{\ding{\numexpr171+\value{footnote}\relax}}
% 注意：圈码只支持到⑩，超过10个脚注需要其他方案

% 超过10个脚注的圈码方案
\usepackage{xunicode-addon}
\renewcommand{\thefootnote}{\textcircled{\arabic{footnote}}}

\begin{document}

体育赛事转播权的法律属性一直存在争议\footnote{王利明: 《物权法论》，中国政法大学出版社2003年版，第156页。}。有学者认为应当将其纳入知识产权的范畴\footnote{苏力: 《法条主义、民意与难办案件》，载《中外法学》2009年第1期，第93页。}。

\end{document}
```

### 方案二: BibLaTeX + 自定义样式（适合文献较多的论文）

```latex
\usepackage[
  backend=biber,
  style=gb7714-2015,      % GB/T 7714-2015 国标样式
  citestyle=gb7714-2015,
  gbfootnote=true,        % 启用脚注模式
]{biblatex}

\addbibresource{references.bib}

% 正文中
体育赛事转播权……\footfullcite{wang2003wuquanfa}

% 文末
\printbibliography
```

### 方案三: GB/T 7714 宏包（适合体育科学等顺序编码期刊）

```latex
\usepackage{gbt7714}
\bibliographystyle{gbt7714-numerical}  % 顺序编码制
% 或
\bibliographystyle{gbt7714-author-year}  % 著者-出版年制

\bibliography{references}
```

## Word实现方案

### 脚注插入
1. 光标定位到引用位置
2. "引用" → "插入脚注"（快捷键 Ctrl+Alt+F / Cmd+Opt+F）
3. 在脚注区域输入完整引用信息
4. 格式设置：宋体/仿宋，小五号字（9pt），单倍行距

### 编号格式调整
1. "引用" → "脚注" → 脚注和尾注对话框
2. 编号格式选择：①②③…… 或 1, 2, 3……
3. 编号方式：连续 或 每页重新编号

### 参考文献管理工具
- **Zotero + 中文引用样式**: 安装 GB/T 7714-2015 CSL 样式文件
- **NoteExpress**: 国内高校常用，内置中文期刊格式
- **知网研学**: 与 CNKI 直接集成

## 引用质量检查清单

### 格式检查
- [ ] 脚注/尾注方式与目标期刊一致
- [ ] 编号格式（圈码/方括号/数字）与目标期刊一致
- [ ] 标点符号全部使用中文全角标点（中文文献部分）
- [ ] 书名号、引号使用正确
- [ ] 页码格式统一（"第X页" vs "页X" vs "p. X"）

### 内容检查
- [ ] 首次引用完整，未遗漏出版信息
- [ ] 重复引用使用正确的简写格式
- [ ] 法律法规条款引用精确到条/款/项
- [ ] 案例引用包含完整案号
- [ ] 外文文献保持原文，未强行翻译
- [ ] 网络文献标注了访问日期
- [ ] 所有引用的文献确实存在且信息准确（参见 citation-discipline.md 的验证原则）

### 实质检查
- [ ] 脚注中的文献确实支持正文中的论断
- [ ] 未张冠李戴（将A的观点归于B）
- [ ] 法律法规引用的是现行有效版本（除非有意引用历史版本）
- [ ] 司法解释的发文字号正确
- [ ] CAS 裁决的案号、当事人、段落号准确

## 与 PRISM 管线的集成规则
