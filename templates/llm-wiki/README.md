# LLM Wiki templates

The canonical seed content (CLAUDE.md schema, `index.md`, `log.md`, example
concept page) is generated by **`tools/llm_wiki.py init`** — that script is the
single source of truth (per `shared-references/integration-contract.md`, one
implementation, not copy-pasted files that drift).

To scaffold a wiki:

```bash
python3 tools/llm_wiki.py init <path>
```

This creates the three-layer structure (`raw/` · `wiki/` · `CLAUDE.md`), seeds
`wiki/index.md` and `wiki/log.md`, drops an example concept page, and copies
`query_wiki.py` + `llm_wiki.py` into `<path>/scripts/` so the wiki is portable.

See `skills/llm-wiki/SKILL.md` for the full workflow and
`shared-references/local-wiki-link.md` for how Prism auto-detects the result.
